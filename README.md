# RA Interactive

Live, interactive portfolio + lead-generation site for **RA Interactive**, a web development agency. Premium dark UI, fully responsive, real embedded live previews, and SEO built to rank.

Built to the project PRD — the site itself is the strongest sample of work.

## Stack

- **Next.js 15** (App Router) + **React 19** + **TypeScript** — SSG for SEO, Vercel-native
- **Tailwind CSS** — dark theme with a single warm amber accent
- **Framer Motion** — scroll-reveal + hero motion (respects `prefers-reduced-motion`)
- **Serverless API route + Resend** — contact form email, no standing server

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm start          # serve the production build
```

Copy `.env.example` → `.env.local` and fill in values. The contact form works
without any env vars in development (it logs submissions server-side); set
`RESEND_API_KEY` to actually deliver email.

## ⭐ Flagship: the live interactive preview (`components/LivePreview.tsx`)

A real, scrollable embedded preview of each project inside a browser-chrome
mockup — not a static screenshot. Hybrid with graceful fallback:

1. **Screenshot-first** — loads a lightweight snapshot by default (fast, always works).
2. **Preview live** — for embeddable sites, swaps to a real `<iframe>` on demand.
3. **Load watchdog** — a 6s timeout + `onLoad` check auto-reverts to the snapshot
   if a site blocks framing, so a blank frame is never shown.
4. **Open live ↗** — always present as the guaranteed path.
5. **Device toggle** — Desktop / Tablet / Mobile resizes the frame width.
6. **Lazy-loaded** — nothing loads until the component scrolls into view (protects
   Core Web Vitals; the homepage stays light).

### Embedding: `allowEmbed`

Many sites send `X-Frame-Options: DENY` / CSP `frame-ancestors`, which can't be
overridden from our side. In `lib/projects.ts`, each project has `allowEmbed`:

- **`true`** — our own hosted projects (e.g. StudyForge on Vercel). Live iframe offered.
- **`false`** — client-owned production sites. Snapshot fallback + "Open live" only.

For our own hosted demos, set `Content-Security-Policy: frame-ancestors 'self'
https://rainteractive.com` (never a blanket `X-Frame-Options: DENY`) so they can
be framed here. Confirm each site's embeddability during build and flip
`allowEmbed` accordingly.

## Preview screenshots

`public/previews/*.svg` are branded placeholders generated by
`node scripts/gen-previews.mjs`. **For production, replace them with real
full-page captures** (the PRD's auto-scroll screenshot fallback) — e.g. Playwright:

```js
const page = await browser.newPage({ viewport: { width: 1280, height: 800 } });
await page.goto(url, { waitUntil: "networkidle" });
await page.screenshot({ path: `public/previews/${slug}.png`, fullPage: true });
```

Then point `project.screenshot` at the `.png`. Everything else keeps working.

## SEO

- Per-page `<title>` + meta description, canonical URLs, semantic headings (one H1/page)
- `sitemap.xml` + `robots.txt`, Open Graph + Twitter cards
- Structured data: Organization + LocalBusiness (root) and BreadcrumbList (case studies)
- Descriptive alt text; static generation for fast Core Web Vitals

## Deploy (Vercel)

1. Push to a Git repo and import into Vercel (zero-config for Next.js).
2. Set env vars from `.env.example` in the Vercel dashboard.
3. On your own hosted demo projects, set the `frame-ancestors` CSP header so they
   embed here.
